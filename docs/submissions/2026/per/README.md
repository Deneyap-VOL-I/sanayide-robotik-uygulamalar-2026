# PER Gönderim Arşivi

Bu klasör, 2026 Sanayide Robotik Uygulamaları Yarışması PER aşamasında T3KYS sistemine gönderilen rapor kopyalarını saklar.

## Dosyalar

- `proje_detay_raporu_submitted.docx`: Gönderilen Proje Detay Raporu DOCX kopyası.
- `proje_detay_raporu_submitted.pdf`: Gönderilen Proje Detay Raporu PDF kopyası.

## Not

Bu klasördeki dosyalar gönderim arşivi olarak kabul edilir. Sonradan düzenleme yapılacaksa bu dosyaların üzerine yazılmamalı; yeni revizyonlar `docs/reports/` veya ayrı bir çalışma klasöründe hazırlanmalıdır.
